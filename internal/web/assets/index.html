外观

终端

100–50000 行，仅限制浏览器显示；原始磁盘历史保持不变。

临时预览不进入复制和历史，收到远端数据后清除。

关键词高亮

规则按顺序匹配，最多 32 条。保留远端 ANSI 颜色，支持 JavaScript Unicode 正则。只改变显示，复制保留原文。

每次扫描最多 200 行 / 64KiB，规则计算超过 1 秒暂停高亮；关闭撤销未保存的预览。

配置管理

主题、字号、滚动历史、高亮、过滤及界面偏好保存在 localStorage。导出不包含连接凭据、命令和输出，也不包含输入解锁状态。

导入校验通过后整体应用。浏览器清理站点数据会移除本地设置。
